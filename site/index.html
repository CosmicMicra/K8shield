Spot attacks in your Kubernetes audit logs

K8Shield learns what normal API activity looks like and flags the outliers: privilege escalation, suspicious pod exec, and secret-scraping bursts. It uses an Isolation Forest and sends alerts to Elasticsearch.

1.2% false positive rate, vs 6.6% for static rules
0.77 F1 score, vs 0.59 for static rules
0.99 ROC AUC

Mean of 5 runs on a synthetic benchmark with injected attacks.

How it works

  1. 1 Read audit logs Every API request the cluster records.
  2. 2 Summarise behaviour Per user and IP, every 5 minutes: volume, errors, RBAC changes, exec, secrets.
  3. 3 Score outliers An Isolation Forest learns normal traffic and scores anything unusual.
  4. 4 Alert Flagged windows go to Elasticsearch with a severity.
